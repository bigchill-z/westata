## Task 1: nlcom / testnl（非线性组合与检验）

**Files:**
- Create: `src/westata/postestimation/nonlinear.py`
- Test: `tests/test_nonlinear.py`

**Stata 语义**（`[R] nlcom`、`[R] testnl`）：对 `g(β)` 用 delta method：

```
Var(g(β)) = G V G'   where G = ∂g/∂β
```

数值梯度用中心差分（步长 `1e-6 * max(1, |β|)`）。

**契约：**

```python
def nlcom(
    result, expression: str, *, level: float = 0.95, eform: bool = False
) -> "LincomResult": ...

def testnl(result, expression: str) -> "WaldTest": ...
```

表达式语法子集（必须支持，其余抛 `ValueError`）：
- `_b[x]`、`_b[Intercept]` → 系数
- `exp()`, `log()`, `sqrt()`, `sin()`, `cos()`, `+ - * / **`、括号、数字常量
- `testnl` 额外支持 `=` 比较（形成一个约束）；多个表达式用逗号或空格分隔表示联合检验

**安全要求**：不要用 `eval`。用 `ast.parse(expression, mode="eval")` 并只允许白名单节点（`Expression`, `BinOp`, `UnaryOp`, `Call`, `Name`, `Constant`, `Subscript`, `Attribute`, `Add/Sub/Mult/Div/Pow`, `USub/UAdd`）。遇到其他节点抛 `ValueError`。

**测试：**
- `nlcom("_b[x1]")` 与 `lincom("x1")` 结果一致（复用 `LincomResult` 字段）
- `nlcom("exp(_b[x1])")` 与手算 `exp(b)` 一致；SE 用手算 `|exp(b)| * se` 校验
- `nlcom("_b[x1] + _b[x2]")` 与 `lincom("x1 + x2")` 一致
- 非法表达式（`__import__`、`open`、属性访问）抛 `ValueError`
- `testnl("exp(_b[x1]) = 2")` 的统计量 = `(g(b)-2)^2 / (G V G')`
- 联合检验：两个表达式 → `df == 2`

## Task 2: lrtest / hausman

**Files:**
- Create: `src/westata/postestimation/modeltests.py`
- Test: `tests/test_modeltests.py`

**`lrtest`（`[R] lrtest`）**：

```
LR = 2 * (ll_unrestricted - ll_restricted) ~ chi2(df_diff)
df_diff = k_unrestricted - k_restricted
```

要求：两个模型必须是嵌套的（restricted 的参数是 unrestricted 的子集）。检查方式：restricted 的每个参数名都在 unrestricted 里，且 `ll` 可比较（`N` 相同）。不满足时抛 `ConsistencyError`。

```python
def lrtest(unrestricted, restricted) -> LRTestResult
# LRTestResult: statistic, df, pvalue, ll_unrestricted, ll_restricted
```

**`hausman`（`[R] hausman`）**：

```
H = (b_fe - b_re)' [V_fe - V_re]^-1 (b_fe - b_re) ~ chi2(k)
```

要求：
- 两个模型参数名一致（取交集，报告被排除的变量）
- `V_fe - V_re` 必须正定；若不正定，Stata 会用广义逆并给出警告。westata 采用同样策略并 `warnings.warn`

```python
def hausman(consistent, efficient) -> HausmanResult
# HausmanResult: statistic, df, pvalue, excluded: list[str]
```

**测试：**
- 嵌套模型 `y ~ x1` vs `y ~ x1 + x2`：LR 与手算 `2*(ll2-ll1)` 一致，`df == 1`
- 非嵌套模型抛 `ConsistencyError`
- Hausman：FE vs RE 在 `xtreg` 场景下统计量有限且 p 值在 [0,1]
- 参数不匹配时报告 excluded

## Task 3: contrast / pwcompare

**Files:**
- Create: `src/westata/postestimation/contrast.py`
- Test: `tests/test_contrast.py`

**Stata 语义**（`[R] contrast`、`[R] pwcompare`）：

- `contrast`：对因子变量做 ANOVA 式对比。支持 `r.`（reference，与基准比）、`g.`（grand mean）、`a.`（adjacent）、`h.`（Helmert）、`m.`（multiple comparisons）
- `pwcompare`：所有两两比较

首期范围（明确）：

```python
def contrast(result, term: str, method: str = "r", *, level=0.95) -> list[MarginsResult]
def pwcompare(result, term: str, *, level=0.95, adjust=None) -> list[MarginsResult]
```

`method` 仅支持 `"r"`、`"g"`、`"a"`；其他抛 `UnsupportedError`。
`adjust` 仅支持 `None`（无调整）；其他抛 `UnsupportedError`（不要假装做了多重比较校正）。

实现方式：对因子各水平构造线性组合权重，复用 `run_lincom`。

**测试：**
- `contrast(result, "C(g)")` 输出长度 = 水平数 - 1（`r.` 法）
- 每个对比的估计值 = 该水平系数 - 基准系数
- `pwcompare` 输出对数 = `k*(k-1)/2`
- 不支持的方法抛 `UnsupportedError`

## Task 4: predict stdp / stdf

**Files:**
- Modify: `src/westata/postestimation/predict.py`（**T4 独占**）
- Test: `tests/test_predict_se.py`

**Stata 语义**（`[R] predict`）：

- `stdp`：拟合值的标准误 = `sqrt(x_i' V x_i)`
- `stdf`：预测值的标准误 = `sqrt(x_i' V x_i + sigma2)`（`sigma2 = e(rmse)^2` 或 MLE 的 `rss/N`）

```python
# 在 predict() 中新增 kind：
#   "stdp" -> sqrt(diag(X V X'))
#   "stdf" -> sqrt(diag(X V X') + residual_variance)
```

`residual_variance` 取 `result.e["rmse"] ** 2`；若缺失，用 `rss/N`（需从 `result.resid` 算）。

**测试：**
- `predict(kind="stdp")` 的平方 == `diag(X V X')`（手算）
- `stdf^2 - stdp^2` 对所有观测为常数，等于 `rmse^2`
- `stdp` 在 `nobs` 与 `len(x)` 不一致时抛错
- 不支持的类型仍抛 `UnsupportedError`
