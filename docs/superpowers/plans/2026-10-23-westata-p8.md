# westata P8 Implementation Plan — 分位数与稳健回归

**Goal:** 实现 `qreg`、`sqreg`、`bsqreg`、`rreg`，并达到与 Stata 数值一致。

**Why this batch is structurally different from P5–P7:** 分位数回归不是极大似然。它最小化**绝对偏差之和**（LAD），因此：

- 没有 `ll`、没有 `chi2`、没有 `r2_p`（Stata 报 `Pseudo R2`，定义不同）
- 推断依赖**稀疏度估计** `f(0)`（残差在 0 处的密度），不是 Hessian
- `sqreg` 需要跨分位数的**联合协方差**，通过 bootstrap 或设计矩阵近似
- `bsqreg` 本身就是 bootstrap

所以不能复用 `_DiscreteBase`。需要新的基类。

### 1.1 LAD 求解器

```python
def solve_lad(X: np.ndarray, y: np.ndarray, *, maxiter: int = 2000,
              tol: float = 1e-10) -> np.ndarray:
    """分位数 τ 的系数，最小化 Σρ_τ(y - Xb)。"""
```

`ρ_τ(u) = u(τ - 1{u<0})`。建议用 **IRLS**（迭代重加权最小二乘）：权重 `w_i = τ/|u_i|` 或 `(1-τ)/|u_i|`，加小常数防除零。**不要**用线性规划——IRLS 更容易达到 Stata 精度且可解释。

收敛判据：系数相对变化 < tol。

### 1.2 `QuantileRegression`

```python
class QuantileRegression:
    @classmethod
    def from_formula(cls, formula, data, *, quantile: float = 0.5) -> "QuantileRegression"
    def fit(self, cov_type="iid", *, reps=0, maxiter=2000, strict=False) -> StataResults
```

`cov_type` 支持 `"iid"`（默认）与 `"robust"`（Stata 的 `vce(robust)`）。

**协方差（关键，最容易错）。已从 `[R] qreg` 手册核实（Methods and formulas）：**

```
cov(β_τ) = τ(1-τ) / f_Y(ξ_τ)^2 * {E(x_i x_i')}^-1
```

即 `V = τ(1-τ) * s_τ^2 * (X'X/n)^-1`，其中 `s_τ = 1/f_Y(ξ_τ)` 是**稀疏度函数**。

**Stata 默认的稀疏度估计是 `fitted` 法，不是核密度。** 手册原文：

> The suboption denmethod specifies the functional form for the sparsity estimator.
> The default is fitted.

`fitted` 法的算法（手册公式 (4)）：

1. 用 Hall-Sheather 带宽 `h`
2. **在 τ+h 和 τ-h 处重新估计分位数回归**，得到 `β_{τ+h}`、`β_{τ-h}`
3. 用样本均值 `x̄` 计算 `F̂^-1(τ±h) = x̄' β_{τ±h}`
4. `ŝ_τ = (x̄'β_{τ+h} - x̄'β_{τ-h}) / (2h)`
5. `f = 1/ŝ_τ`

**必须实现这个三步重估**，否则标准误全错。只估一次然后用核密度是 `kernel()` 选项，不是默认。

带宽（手册原文，`100(1-α)` 是置信水平）：

```
h_s (Hall-Sheather) = n^(-1/3) * Φ^-1(1-α/2)^(2/3)
                      * [ 1.5 * φ(Φ^-1(τ))^2 / (2*Φ^-1(τ)^2 + 1) ]^(1/3)
h_b (Bofinger)      = n^(-1/5) * [ 4.5 * φ(Φ^-1(τ))^4 / (2*Φ^-1(τ)^2 + 1)^2 ]^(1/5)
h_c (Chamberlain)   = Φ^-1(1-α/2) * sqrt(τ(1-τ)/n)
```

默认用 `h_s`。注意 `h_s` 与 `h_c` 依赖置信水平 α，`h_b` 不依赖。

**其他选项**（`vce(iid, residual)` 与 `vce(iid, kernel(...))`）不是默认，首期只需实现 `fitted`；但**必须让传错选项时报错而非静默使用默认**。

`vce(robust)` 在 Stata 中可用（实测 `qreg y x1 x2, quantile(.5) vce(robust)` 被接受）。手册未单列其公式，但实测与默认仅差 0.8%（同方差 DGP）：

| 方法 | x1 标准误 |
|---|---|
| 默认 iid/fitted | .0355009 |
| vce(robust) | .0352211（99.2%） |
| vce(iid, residual) | .0349172（98.4%） |
| vce(iid, kernel) | .0457925（129%） |

**实施建议**：先实现默认 `iid/fitted` 并达到 E3；`vce(robust)` 若无法确定精确公式，标记为 E2 并在 registry 注明，不要凭猜实现。

`model_name = "qreg"`，`dist = "t"`，`df_resid = n - k`。

`e()` 需包含：`N`、`df_m`、`df_r`、`q`（分位数）、`sum_adev`（最小绝对偏差和）、`sum_rdev`（原始偏差和）、`r2_p`（Pseudo R2 = 1 - sum_adev/sum_rdev）、`rank`。

**注意**：`Pseudo R2 = 1 - (最小Σ|u|) / (原始Σ|u|)`，其中原始是只含常数项的模型。与 OLS 的 R² 完全不同。

### 1.3 `RobustRegression`（`rreg`）

Stata 的 `rreg` 是**迭代重加权最小二乘 + Huber 权重**：

1. OLS 起步
2. 计算残差，`s = median(|u|) / 0.6745`
3. 权重 `w_i = 1` 若 `|u_i|/s <= c`，否则 `c / (|u_i|/s)`，`c = 7`（Stata 默认 `c(7)`）
4. 加权 OLS，重复直至收敛

手册实测输出显示 Stata 先跑 **Huber 迭代**收敛，再切到 **biweight 迭代**：
`. rreg y x` → `Huber iteration 1..3` 然后 `Biweight iteration 4..8`。
首期只实现 Huber 部分（`c(7)`），把 biweight 标为未实现并在 e() 注明，
不要假装两者都做了。
5. `e(scale) = s`，标准误按加权 OLS 的公式（Stata 用 `s^2 * (X'WX)^-1`）

```python
class RobustRegression:
    @classmethod
    def from_formula(cls, formula, data, *, tune: float = 7.0) -> "RobustRegression"
    def fit(self, ...) -> StataResults
```

`model_name = "rreg"`。

**测试要求（TDD）**
- `solve_lad` 在中位数（τ=0.5）上与 `np.median` 的常数模型一致
- `qreg` 系数与 Stata 对拍（τ=0.25/0.5/0.75/0.9），系数容差 1e-3
- `qreg` 的 `Pseudo R2` 与 Stata 一致（0.6424 / 0.6361）
- `qreg` 标准误与 Stata 一致（**这个最关键**，容差 5e-2，因为核密度估计有实现自由度）
- `qreg` 在 **同方差** DGP 上，τ=0.5 系数接近 OLS
- `qreg` 拒绝 `quantile` 不在 (0,1)
- `rreg` 在污染数据上比 OLS 更接近真实参数 2.0
- `rreg` 的 `e(scale)` 有限且 > 0
- `e()` 键完整、`summary(style="stata")` 可渲染

### 2.1 `Sqreg`（`sqreg`）

同时估计多个分位数的系数，并给出**联合协方差矩阵**（跨分位数的交叉项）。

Stata 的实现：`sqreg` 通过对**同一次 bootstrap 重抽样**估计所有分位数，从而得到联合分布。

```python
class Sqreg:
    @classmethod
    def from_formula(cls, formula, data, *, quantiles=(0.25,0.5,0.75)) -> "Sqreg"
    def fit(self, *, reps: int = 200, strict=False, seed=None) -> StataResults
```

结果：`params` 为拼接的向量（q1 的 k 个系数，q2 的 k 个...），`cov` 为 `(m*k) x (m*k)` 块矩阵。

`model_name = "sqreg"`。

**参数命名**：`f"q{τ}:{name}"`，例如 `q0.25:x1`。

### 2.2 `Bsqreg`（`bsqreg`）

单分位数的 bootstrap 标准误。

```python
class Bsqreg:
    @classmethod
    def from_formula(cls, formula, data, *, quantile=0.5) -> "Bsqreg"
    def fit(self, *, reps: int = 200, seed=None, strict=False) -> StataResults
```

系数与 `qreg` 相同（同一估计量），只有标准误来自 bootstrap（百分位法）。

**测试要求（TDD）**
- `sqreg` 的单分位数结果与该分位数的 `qreg` 系数一致（1e-6）
- `sqreg` 的协方差是对称半正定
- `bsqreg` 的系数与 `qreg` 完全一致（同一估计量，1e-10）
- `bsqreg` 的标准误与 `qreg` 的 iid 标准误在同一量级（比值在 0.5–2 之间）
- `reps` <= 0 抛 `ValueError`
- 固定 `seed` 时结果可复现
