## Task 1: 权重层（Lead）

**Files:**
- Create: `src/westata/data/__init__.py`
- Create: `src/westata/data/weights.py`
- Test: `tests/test_weights.py`

**契约：**

```python
@dataclass(frozen=True)
class WeightSpec:
    weights: np.ndarray    # 归一化后的权重（估计直接用）
    weight_type: str       # 原始类型
    effective_n: float     # df 用的有效样本量
    implies_robust: bool   # pweight=True

def normalize_weights(weights, weight_type: str) -> WeightSpec:
    """按 Stata [U] 20.24 归一化。"""
```

规则（来源：Stata `[U] 20.24`）：
- `fweight`：权重原样返回；`effective_n = sum(w)`；`implies_robust=False`
- `aweight`：`w * N / sum(w)`；`effective_n = N`；`implies_robust=False`
- `pweight`：同 aweight 归一化；`effective_n = N`；**`implies_robust=True`**
- `iweight`：原样返回；`effective_n = sum(w)`；`implies_robust=False`
- 负权重、全零权重、`weight_type` 不在上述四种之一 → 抛 `WeightError`
- 权重长度不匹配 → `WeightError`

**测试：** 四种类型的归一化结果、`effective_n`、`implies_robust` 标志、非法输入。

## Task 2: 加权 OLS（Lead）

**Files:**
- Modify: `src/westata/estimators/linear.py`
- Test: `tests/test_ols_weights.py`

要点：
- `weights` + `weight_type` 走 `normalize_weights`；未给 `weight_type` 而给了 `weights` → `WeightError`
- 加权点估计：`β = (X'WX)^-1 X'Wy`，用 `sqrt(w)` 缩放后再 `lstsq`
- `df_resid = effective_n - k`
- `pweight` 且未显式指定 `cov_type` → 自动用 `"HC1"`（对应 Stata `vce(robust)`），并在结果 `cov_type` 标注
- `e` 里的 `N` 用 `effective_n`（fweight 时是 `sum(w)`）

**测试：**
- `fweight` 结果 == 按权重展开数据后的无权重 OLS（Stata 手册明确的最小定义）
- `aweight` 权重归一化后结果与 statsmodels `WLS` 一致
- `pweight` 默认走 HC1
- 非法权重抛错

## Task 3: IV（subagent-iv）

**Files:**
- Create: `src/westata/estimators/iv.py`
- Test: `tests/test_iv.py`

**契约：**

```python
class IV2SLS:
    @classmethod
    def from_formula(cls, formula, data, *, weights=None, weight_type=None): ...
    def fit(self, cov_type="nonrobust", cov_kwds=None, ssc=None) -> StataResults: ...

class IVLIML(IV2SLS): ...
class IVGMM(IV2SLS): ...
```

- 公式语法：`"y ~ exog + [endog ~ instruments]"`（linearmodels 原生语法，与 statsmodels 风格兼容）。
- 后端：`linearmodels.iv.IV2SLS` / `IVLIML` / `IVGMM`。
- `cov_type="nonrobust"` → linearmodels `cov_type="unadjusted"`；`"HC1"` → `"robust", debiased=True`；`"cluster"` → `"clustered", clusters=...`。
- `e` 键：`N`, `df_m`, `df_r`, `r2`, `r2_a`, `rmse`, `F`（第一阶段 F 或整体 F，注明）, `ll`, `rank`。
- 无权重支持（P1 范围外），传 `weights` 抛 `UnsupportedError`。

**测试：**
- 2SLS 点估计与 `linearmodels` 未校正结果 1e-12 一致
- 恰好识别与过度识别两种情况
- 弱工具变量不报错但给出 warning
- `df_r` 与 Stata `ivregress` 一致（`N - K`，K 含内生回归元与工具变量去重后的参数个数）

## Task 4: HDFE（subagent-hdfe）

**Files:**
- Create: `src/westata/estimators/hdfe.py`
- Test: `tests/test_hdfe.py`

**契约：**

```python
class FEOLS:
    @classmethod
    def from_formula(cls, formula, data, *, weights=None, weight_type=None): ...
    def fit(self, cov_type="nonrobust", cov_kwds=None, ssc=None) -> StataResults: ...
```

- 公式：`"y ~ x1 + x2 | fe1 + fe2"`（PyFixest 原生语法）。
- 后端：`pyfixest.feols`。
- `cov_type` 映射：`"nonrobust"` → `vcov=None`；`"HC1"` → `"hetero"`；`"cluster"` → `"cluster"` + `vcov_kwargs={"cluster": ...}`。
- `ssc` 映射到 PyFixest `ssc(k_adj=..., G_adj=..., G_df=...)`，默认 `k_adj=True, G_adj=True, G_df="min"`（对齐 reghdfe）。
- 从 PyFixest 结果提取系数、标准差、R²、N，装进 `StataResults`。
- `e` 键：`N`, `df_m`, `df_r`, `r2`, `r2_a`, `rmse`, `F`, `rank`；聚类时加 `N_clust`。
- 被吸收（collinear）的变量必须在结果里标注，不能静默丢弃。

**测试：**
- 单固定效应 FE 与 `statsmodels` 加虚拟变量 OLS 系数 1e-10 一致
- 双向固定效应与双向 demean 后 OLS 一致
- 聚类 SE 与 P0 的 `compute_cov` 在同一需求下一致（用 demean 后设计矩阵交叉验证）
- 与无固定效应时 `FEOLS` 退化为 OLS

**契约：**

```python
class PanelOLS:
    @classmethod
    def from_formula(cls, formula, data, *, entity, time): ...
    def fit(self, entity_effects=True, time_effects=False,
            cov_type="nonrobust", cov_kwds=None, ssc=None) -> StataResults: ...

class BetweenOLS(PanelOLS): ...
class FirstDifferenceOLS(PanelOLS): ...
```

- 后端：`linearmodels.panel`。
- 数据需 `entity`/`time` 两列；内部 `set_index([entity, time])`。
- `cov_type` 映射同 Task 3（linearmodels 的 `unadjusted`/`robust`/`clustered`）。
- `RandomEffects` 必须用 linearmodels 的默认 Swamy-Arora 估计，不得替换。
- `xtreg, fe` 的 `df_r` 对齐 Stata：`N - K - n_entities + 1`（组内变换后）。实现时用 `auto_df` 或显式推导，并在测试中写明依据。
- `e` 键同 Task 4。

**测试：**
- FE 与 `within` 变换后的 OLS 一致
- RE 与 linearmodels `RandomEffects` 一致
- BE 与组均值 OLS 一致
- FD 与一阶差分 OLS 一致
- 不平衡面板可用
