## 2. 论文的论证过程（直白版）

### 2.1 论文想回答什么

法国大革命（1789）及随后的拿破仑时期，法军占领并改造了德意志西部大片地区。改造内容包括：
废除农奴制、废除行会、引入民法典、统一度量衡与税制。

论文问：**这些"激进制度改造"有没有带来长期经济后果？**

度量方式是用城市化率（`urbrate`，城镇人口占比）作为经济表现的代理。

### 2.2 识别的核心变量

关键自变量是 `fpresence`——**法国势力存在的年数**。这个变量是跨时不变的国别特征，
论文把它与**世纪虚拟变量交互**：

```
urbrate ~ fpresence1750 + fpresence1800 + fpresence1850 + fpresence1875 + fpresence1900
        + 年份虚拟变量  |  邦固定效应
```

这样每列报告 5 个系数，刻画法国影响的**时间路径**。

**为什么这样设计**：如果制度改造真的有效，效应应该**随时间累积**——1850 年、1875 年、
1900 年的系数应该显著，而 1750 年（改革前）应该不显著。

论文每列还报告一个**联合检验**：`test fpresence1850 fpresence1875 fpresence1900`，
检验"改革后的三个系数是否同时为零"。**这才是论文结论的形式**。

### 2.3 固定效应与权重

- **邦固定效应**：吸收"某邦一直城市化程度高"这类跨时不变差异（地理、初始条件）；
- **年份虚拟变量**：吸收"所有邦在这一时期都城市化"的共同趋势；
- **`[aweight=totalpop1750]`**：按 1750 年人口加权，让大国主导估计；
- **`cluster(id)`**：标准误聚类在邦层面（同一邦的跨期观测相关）。

剩余的识别变异是：**同一邦，在法国影响更长的那些时期，城市化是否走得更快**。

### 2.4 稳健性：四列样本/权重组合

论文 Table 3 的四列刻意交叉：

| 列 | 样本 | 权重 |
|---|---|---|
| (1) | 易北河以西（受法国影响） | 加权 |
| (2) | 易北河以西 | 无权重 |
| (3) | 全部邦 | 加权 |
| (4) | 全部邦 | 无权重 |

逻辑：**如果结论依赖某个特定的样本或权重选择，它就不可信**。四列结论一致才站得住。

Table 4 列 (1) 在此基础上再剔除一个邦（`id≠2`），检验是否被离群值驱动。

### 3.1 主表：Stata vs westata

|---|---|---|---|---|---|---|
| 3(1) | 易北河以西 | 是 | 74 | 0.633869 / 0.633869 | 10 | **是** |
| 3(2) | 易北河以西 | 否 | 74 | 0.528890 / 0.528890 | 10 | **是** |

### 3.2 逐参数对齐

| 规格 | 参数 | 系数最大相对差 | 标准误最大相对差 | 联合 F（Stata） | 联合 F（westata） |
|---|---|---|---|---|---|
| T3_c1 | 10 | 4.81e-14 | 1.47e-14 | 3.406308 | 3.406308 |
| T3_c2 | 10 | 3.41e-13 | 3.99e-14 | 0.914230 | 0.914230 |
| T3_c3 | 10 | 4.83e-15 | 2.04e-14 | 4.193100 | 4.193100 |
| T3_c4 | 10 | 5.17e-13 | 2.53e-14 | 1.646595 | 1.646595 |

**系数最大相对差 5.2e-13，标准误 4.0e-14，联合 F 统计量逐位相同。**

联合检验的一致尤其说明问题：它不是单个系数的函数，而是**整个协方差矩阵的函数**。
F 相同意味着 `e(V)` 在数值上也一致，不只是对角线。

### 3.3 怎么读这些结果

以 Table 3 列 (1)（论文基准列）为例：

| 项 | 系数 | 含义 |
|---|---|---|
| fpresence1750 | −0.491 | 改革前：法国影响越长，城市化反而**更低** |
| fpresence1800 | −0.247 | |
| fpresence1850 | −0.160 | |
| fpresence1875 | **+0.402** | 改革后转为正 |
| fpresence1900 | **+0.634** | 效应最强 |

**这个符号翻转是论文论证的核心**：法国影响在改革前与城市化**负相关**（说明存在选择效应——
法国更可能占领富裕地区，或者反之），但改革后转为显著正相关。

**联合检验 F = 3.406**（对应 p = 0.053）说明：改革后的三个系数**在 10% 水平上联合显著**，在 5% 水平上处于边缘。
这正是论文结论的形式——不是"某一个系数显著"，而是"改革后的效应整体"。

**一个必须如实说明的观察**：五列中只有 **2 列**的联合检验在 10% 水平上显著。

| 规格 | 联合 F | p 值 | 10% 显著 |
|---|---|---|---|
| T3_c1（加权、易北河以西） | 3.406 | 0.053 | **是** |
| T3_c2（无权重、易北河以西） | 0.914 | 0.463 | 否 |
| T3_c3（加权、全部邦） | 4.193 | 0.021 | **是** |
| T3_c4（无权重、全部邦） | 1.647 | 0.214 | 否 |
| T4_c1（加权、剔除 id=2） | 2.353 | 0.128 | 否 |

**加权列显著，无权重列不显著。** 这个规律很整齐，说明结论对权重选择敏感——
而权重（1750 年人口）正是这类历史面板里最有争议的设定之一。

我要说清楚：**这是我从复现输出里观察到的，不是对论文的评判**。论文的稳健性表
本来就是为暴露这类敏感性而设计的；我无法核对论文自己怎么讨论这一点，因为拿不到原文。
但这恰恰是"缺少作者 log/原文"这个边界的实际代价——**我能复现数字，却无法判断
这些数字在论文论证中扮演什么角色**。

### 3.4 稳健性四列的一致性

四列的 1900 年系数分别在 0.503–0.634 之间，**符号与量级一致**。这支持论文的核心主张
不依赖特定的样本或权重选择。

## 4. 本章的核心发现：`PanelOLS` 不接受权重

### 4.1 现象

论文的命令是 `xtreg, fe [aweight=...]`。文档把 `xtreg` 映射到 `PanelOLS`：

```python
ws.PanelOLS.from_formula("urbrate ~ x", df, entity="id", time="year",
                         weights=df.totalpop1750)
# TypeError: PanelOLS.from_formula() got an unexpected keyword argument 'weights'
```

`PanelOLS.from_formula` 的签名是 `(formula, data, *, entity, time, subset=None)`——
**没有 `weights`**。

### 4.2 影响

本篇 5 个复现规格中 **4 个是加权的**。用文档指定的对应物，只能做 1 列。

### 4.3 但这不阻碍完成任务

`FEOLS` 与 `Areg` 都接受权重，且都实现同一 within 估计量。实测：

| 估计器 | 接受权重 | 加权聚类 SE 与 Stata 一致 |
|---|---|---|
| `PanelOLS` | ✗ | — |
| `FEOLS` | ✓ | **✓ 精确一致**（0.407511） |
| `Areg` | ✓ | ✗（0.452923，偏 11%） |

**本次复现用 `FEOLS`**，系数与标准误均精确吻合。

所以这是**映射层面的缺口**，不是能力缺口——但用户会先试文档指定的那个。

### 4.4 分级：P2

会立刻抛 `TypeError`（不误导），且有精确的替代路径。但"文档指定的对应物缺参数"
会让人绕路。详见 [ajr2001_gaps.md](../gaps/ajr2001_gaps.md) §1。

## 5. 关于基准的诚实说明

### 5.1 为什么没有论文数字

| 来源 | 状态 |
|---|---|
| 作者 log | **复现包内没有**（只有 do、dta、readme） |
| AER 原文 PDF | 付费墙拦截（返回 HTML 而非 PDF） |
| NBER 工作论文 | 尝试的编号对应另一篇论文 |

### 5.2 这限制了结论的强度

| 说法 | 是否成立 |
|---|---|
| "论文的 Table 3 被复现" | **不能声称** |
| "westata 能复现 Stata 在作者规格上的输出" | **成立**，到 1e-13 |
| "这支管线的数值正确性" | **成立**，但因为两侧同源（都读同一 dta、跑同一条命令），它能测的是**估计器实现**，不是**数据构造** |

**最后一条值得强调**：如果数据自身有误、或者我的样本限制与作者不同，这次复现**发现不了**——
因为两侧用的是同一份数据、同一个限制。这正是"有作者 log"的前几篇更强的地方。

### 5.3 如果要升级为完整复现

需要 AER 2002 那篇的 Table 3 与 Table 4 数字。拿到之后，把 `ajr2001_specs.py` 里预留的
`PAPER` 字典填上，`run_compare.py` 就能同时对照两套基准。

## 8. 一句话总结

> **在论文自己的规格上，westata 与 Stata 精确一致**——5 列、50 个参数，系数到 5.2e-13，
> 聚类标准误到 4.0e-14，连联合 Wald 检验的 F 统计量都逐位相同。**但这份复现无法证明论文的数字是对的**：
> 归档里没有作者 log，AER 原文在付费墙后，因此基准只能是 Stata 自己的输出。
> 这条边界比任何数字都更需要放在前面——它决定了这次复现能声称什么。
>
> 附带发现：文档把 `xtreg` 映射到 `PanelOLS`，而 `PanelOLS` **不接受权重**，导致本篇
> 4/5 的加权列用不了它；`FEOLS` 可以且精确，但用户会先试那个对应物。
