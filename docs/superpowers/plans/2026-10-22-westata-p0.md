**Tech Stack:** Python 3.10、numpy、pandas、scipy、statsmodels、patsy、pytest、pyyaml、pyreadstat。

**对外契约（必须严格实现）：**

```python
# vce/dispatch.py
def compute_cov(
    X: np.ndarray,                 # n x k
    resid: np.ndarray,             # n
    *,
    cov_type: str = "nonrobust",   # "nonrobust"|"HC0".."HC3"|"cluster"
    cov_kwds: Mapping[str, Any] | None = None,
    ssc: SSC | None = None,
    nobs: int | None = None,
    df_resid: float | None = None,
) -> tuple[np.ndarray, float]:
    """返回 (cov, df_t)。df_t 为 t 检验自由度。"""
```

规则：
- `bread = inv(X.T @ X)`
- `HC0 = bread @ (X.T * resid**2) @ X @ bread`
- `HC1 = HC0 * N/(N-K)`（`ssc.adj=True`）
- `HC2`：把 `resid**2` 换成 `resid**2/(1-h_i)`
- `HC3`：`resid**2/(1-h_i)**2`，其中 `h_i = diag(X @ bread @ X.T)`
- `cluster`：`meat = Σ_g (X_g.T @ resid_g)(X_g.T @ resid_g).T`；`cov = f * bread @ meat @ bread`，`f = (N-1)/(N-K) * G/(G-1)`（`ssc.adj and ssc.cluster_adj`）；`df_t = G - 1`
- `df_t`：nonrobust/HC 为 `N-K`；cluster 为 `G-1`
- 未知 `cov_type` 抛 `ValueError`，消息列出支持值

**测试（必须包含）：**

```python
import numpy as np

def _toy():
    rng = np.random.default_rng(0)
    X = np.column_stack([np.ones(30), rng.normal(size=30)])
    beta = np.array([1.0, 2.0])
    resid = rng.normal(size=30)
    return X, resid, np.linalg.inv(X.T @ X)

def test_hc1_matches_manual_formula():
    X, u, bread = _toy()
    n, k = X.shape
    cov, df_t = compute_cov(X, u, cov_type="HC1")
    meat = (X.T * u**2) @ X
    expected = (n / (n - k)) * bread @ meat @ bread
    np.testing.assert_allclose(cov, expected, rtol=1e-12)
    assert df_t == n - k
```

```python
class StataResults:
    def __init__(
        self,
        *,
        params: np.ndarray,
        param_names: list[str],
        cov: np.ndarray,
        resid: np.ndarray,
        fittedvalues: np.ndarray,
        nobs: int,
        df_resid: float,
        df_model: float,
        dist: str = "t",            # "t" 或 "z"
        model_name: str = "",
        cov_type: str = "nonrobust",
        e: Mapping[str, Any] | None = None,
    ): ...

    # 属性
    params, bse, tvalues, pvalues, nobs, df_resid, df_model,
    resid, fittedvalues, cov, llf, rsquared, rsquared_adj, aic, bic
    # 方法
    cov_params() -> np.ndarray
    conf_int(alpha: float = 0.05) -> pd.DataFrame
    summary(style: str = "statsmodels") -> str
    # Stata e()
    e: EReturn
```

要点：
- `params`/`bse`/`tvalues`/`pvalues` 用 pandas Series（索引为变量名）。
- `dist=="z"` 时 `tvalues` 返回 z 值（属性名仍叫 `tvalues`，另提供 `zvalues` 别名）。
- `summary(style="stata")` 必须包含：`Number of obs`、`F(...)` 或 `Wald chi2(...)`、`Prob > F`/`Prob > chi2`、`R-squared`、`Adj R-squared`、`Root MSE`，以及系数表头 `Coef.`、`Std. err.`、`t`/`z`、`P>|t|`、`[95% conf. interval]`。
- `EReturn` 为 dict 子类，支持 `e["r2_a"]` 与 `e.r2_a` 两种访问。
- 缺失值：`e` 中不存在的键返回 `None`，不抛 KeyError。

要点：

- 缺失值 listwise 删除，返回保留行的索引，供 endog 对齐。

**测试：**

```python

class OLS:
    def __init__(self, endog, exog, *, weights=None, weight_type=None): ...
```
