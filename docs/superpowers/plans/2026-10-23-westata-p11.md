# westata P11 Implementation Plan — 因果推断

**Goal:** 实现 `teffects`（ra/ipw/aipw/nnmatch）与 `didregress`/`xtdidregress`。

**为什么这批的难点不是估计量而是标准误：** 每个 `teffects` 估计量都只是几行代数。真正难的是：

1. **估计目标（estimand）**：`ate` 与 `atet` 是两个不同的量，每个数字都会变
2. **影响函数（influence function）**：标准误来自 IF，写错时**点估计仍然看起来正常**
3. **`po` 分解**：Stata 报的是潜在结果均值 `POmean`，不只是差值

所以 fixture 必须同时记录 **ATE 与 POmean 的值和标准误**。

## Task 1: teffects

**Files:** `src/westata/estimators/treatreg_effects.py`、`tests/test_teffects.py`

### 1.1 共同结构

```python
class TreatmentEffectResult:
    estimand: str          # "ATE" | "ATET"
    estimate: float
    std_err: float
    z: float
    pvalue: float
    ci: tuple[float, float]
    potential_outcomes: dict[str, tuple[float, float]]   # {"0": (mean, se), "1": (mean, se)}

class _TreatmentBase:
    @classmethod
    def from_formula(cls, outcome: str, treatment: str, data, *, estimand="ate") -> ...
    def fit(self) -> TreatmentEffectResult
```

### 1.2 `RegressionAdjustment`（`teffects ra`）

1. 对处理组和对照组**分别**拟合 `y ~ x`
2. 预测每个观测在两种状态下的 `y`：`ŷ0`, `ŷ1`
3. **ATE** = mean(ŷ1 − ŷ0)；**ATET** = mean over treated of (ŷ1 − ŷ0)

`POmean(0)` = mean(ŷ0)；`POmean(1)` = mean(ŷ1)。

### 1.3 `IPW`（`teffects ipw`）

1. Logit 拟合处理方程，得倾向得分 `p̂`
2. **ATE** = mean[t·y/p̂ − (1−t)·y/(1−p̂)]
3. **ATET** = mean[t·y/p̂] / mean[t/p̂] − mean[(1−t)·y·p̂/(1−p̂)] / mean[(1−t)·p̂/(1−p̂)]

### 1.4 `AIPW`（`teffects aipw`）

RA + IPW 的增广：先做 RA 预测，再用 IPW 权重校正残差。

```
ATE = mean[ (t·(y − ŷ1)/p̂ + ŷ1) − ((1−t)·(y − ŷ0)/(1−p̂) + ŷ0) ]
```

### 1.5 `NearestNeighbourMatching`（`teffects nnmatch`）

对不同组按协变量距离找 `nneighbor` 个最近邻，用其 `y` 填补反事实。
首期只做**无放回、欧氏距离、Abadie-Imbens 标准误**。

**标准误要求**：所有估计量都必须用**影响函数**（influence function）计算，不是 OLS 的现成公式。若无法精确实现，**报告实测差距并标 E2**，不要用其他公式冒充。

## Task 2: DID

**Files:** `src/westata/estimators/did.py`、`tests/test_did.py`

### 2.1 `Didregress`（`didregress`）

两向固定效应 DID：

```
y_it = α_i + λ_t + β·D_it + x_it'γ + ε_it
```

ATET = β̂。标准误按 `group(unit)` 聚类。

```python
class Didregress:
    @classmethod
    def from_formula(cls, outcome, treatment, data, *, group, time) -> "Didregress"
    def fit(self, cov_type="cluster") -> StataResults
```

复用 `estimators/hdfe.py` 的两向固定效应吸收。

**关键**：`didregress` 的 `treated` 必须是**时变**变量（组×期的交互）。我第一次用时不变得，Stata 报 `r(198) treatment omitted because of collinearity`——那是对的，因为时不变的组指示就是固定效应本身。

### 2.2 `Xtdidregress`（`xtdidregress`）

面板版本，语义与 `didregress` 相同（Stata 两者在平衡面板上给出相同结果）。
