# westata P13 Implementation Plan — 重抽样

**Goal:** 实现 `bootstrap`、`jackknife`、`permute`。

**为什么这批的验证标准与其他批次不同：**

Bootstrap 的结果依赖随机数流。Stata 的 RNG 与 numpy 不同，**逐次重复对拍在原理上不可能**。所以本批的验收标准必须分层：

| 层次 | 可验证性 | 方法 |
|---|---|---|
| **Jackknife** | **完全确定性**，无 RNG | 全精度 `e(V)` 对拍 |
| **Bootstrap 点估计** | 确定（不依赖重抽样） | 精确对拍 |
| **Bootstrap 方差** | 统计量，依赖 RNG | 只能验证量级与一致性，标 E2 |
| **Permute 的 p 值** | 依赖 RNG | 同上 |

**把可确定的部分（jackknife）做到精确，把依赖随机的部分明确标 E2** ——这是唯一诚实的做法。

### 已验证的精度极限（重要，写进契约）

我用**直接重新拟合**的留一估计得到：

| 量 | 我的结果 | Stata | 差距 |
|---|---|---|---|
| `mean` 的 b | 0.7552785610919946 | 同 | **0** |
| `mean` 的 V | 0.015102296278653142 | 0.015102300026884398 | **3.7e-9** |
| `regress` 的 b | 全部 | 同 | **8.9e-16** |
| `regress` 的 V | — | — | **7.4e-6** |

**7.4e-6 的来源已诊断，不是公式错误**：用单一缩放因子 `0.9974973603895577` 拟合后残差降到 7.7e-9，与 `(n-1)/n = 0.9975` 差 2.6e-6——说明**因子正确，是留一估计值本身在第 6 位后不同**。

最可能的原因：Stata 用 **Sherman–Morrison 快速更新**计算留一估计，而非重新拟合。两者在数学上等价，在浮点运算上不同。

**契约要求**：实现必须用直接重新拟合（可解释、可验证），并接受 `regress` 的 V 有约 1e-5 的差距。**不要为了对上 7e-6 去猜 Stata 的更新公式**——那会把可解释的实现换成不可验证的。

## Task 1: 三种重抽样

**Files:** `src/westata/estimators/resample.py`、`tests/test_resample.py`

### 1.1 `Jackknife`

```python
class Jackknife:
    @classmethod
    def from_formula(cls, formula, data, *, method="regress") -> "Jackknife"
    def fit(self) -> StataResults
```

**公式**（`[R] jackknife`，默认形式）：
```
θ̂_(j) = 留一 j 后的估计
V = (N-1)/N · Σ_j (θ̂_(j) − θ̂_(·))(θ̂_(j) − θ̂_(·))'
```

用**直接重新拟合**，不用快速更新。

### 1.2 `Bootstrap`

```python
class Bootstrap:
    @classmethod
    def from_formula(cls, formula, data, *, reps=200, seed=None) -> "Bootstrap"
    def fit(self) -> StataResults
```

百分位法或正态近似，必须**记录 seed** 且可复现。

### 1.3 `Permute`

```python
class Permute:
    @classmethod
    def from_formula(cls, formula, data, *, reps=200, seed=None) -> "Permute"
    def fit(self) -> StataResults
```

随机置换指定变量的值，重算统计量，p 值 = 超过观测值的比例。

**测试要求（TDD）**
- `Jackknife` 的 b 与 V 对全精度基准（b 1e-12，V **1e-5**——见上）
- `Jackknife` 的 b 与 `ws.OLS` 完全一致（1e-12）
- `Bootstrap` 固定 seed 时**可复现**（两次运行结果相同）
- `Bootstrap` 的标准误与解析 VCE 在同一量级（比值 0.5–2）
- `Bootstrap` 的点估计不依赖重抽样（等于原样本估计，1e-12）
- `Permute` 的 p 值在 [0,1]
- `reps <= 0` 抛 `ValueError`

## 3. 明确不做

| 命令 | 原因 |
|---|---|
| `bootstrap` 的自定义统计量语法 | 需要解释器，见 §4 |
| `bs` 的 `r()` 任意提取 | 同上 |
| 分层/整群 bootstrap | 首期只做简单随机重抽样 |
| `permute` 的 `enumerate` 完全枚举 | 组合爆炸 |

## 4. 关于任意统计量表达式

Stata 的 `bootstrap r(mean), ...: summarize y` 允许任意 `r()` 结果。这等价于实现一个小型解释器。**首期只支持**：
- 回归系数（`bootstrap: regress`）
- 均值（`bootstrap: mean`）

其他抛 `UnsupportedError`，并说明原因。
