### 1.1 `Truncreg`（Stata `truncreg`）

截断回归：观测只在 `(ll, ul)` 内可见。对数似然（`[R] truncreg`）：

```
lnL = Σ [ -ln(σ) - 0.5·ln(2π) - 0.5·((y-xb)/σ)²
          - ln(Φ((ul-xb)/σ) - Φ((ll-xb)/σ)) ]
```

```python
class Truncreg(_DiscreteBase):
    def __init__(self, endog, exog, *, lower=None, upper=None, param_names=None)
    @classmethod
    def from_formula(cls, formula, data, *, lower=None, upper=None)
```

要求：`lower` 与 `upper` 至少给一个；`lower >= upper` 抛 `ConsistencyError`。

### 1.2 `Intreg`（Stata `intreg`）

区间回归：只知道 `y` 落在 `[lower, upper]`。

```
lnL = Σ ln( Φ((upper-xb)/σ) - Φ((lower-xb)/σ) )
```

```python
class Intreg(_DiscreteBase):
    def __init__(self, lower, upper, exog, *, param_names=None)
    @classmethod
    def from_formula(cls, formula, data)   # formula 左侧写 "lower upper" 两列
```

### 1.3 `Heckman`（Stata `heckman`）

样本选择模型。两个方程：

```
选择方程:  s* = z·γ + u,   s = 1[s* > 0]
主方程:    y  = x·β + ε,   仅当 s = 1 时观测
(u, ε) ~ BVN(0, 0, 1, σ, ρ)
```

两步法（Heckman 1979）：
1. probit 估 γ，算 IMR `λ = φ(zγ)/Φ(zγ)`
2. OLS 回归 `y ~ x + λ`（仅 s=1），但标准误需要校正

**首期只做两步法**，MLE 抛 `UnsupportedError`。原因为 MLE 需要对 ρ 联合优化、收敛脆弱，且两步法结果可精确对拍。

```python
class Heckman:
    @classmethod
    def from_formula(cls, formula, data)   # "y ~ x + select(s ~ z)"
    def fit(self, method="twostep", ...) -> StataResults
```

`e` 需要额外包含 `rho`、`sigma`、`lambda`（IMR 均值）。

### 1.4 `Etregress`（Stata `etregress`）

内生处理效应。首期只做**控制函数法**（control function），即把第一阶段残差加入主方程；MLE 抛 `UnsupportedError`。

```python
class Etregress: ...  # from_formula("y ~ x + treat(t ~ z)")
```

**测试要求（TDD）**
- `Truncreg` 在无截断（lower/upper 极远）时退化为 OLS，参数一致到 1e-6
- `Truncreg` 对数似然与手写公式一致到 1e-10
- `Intreg` 在 `lower == upper == y` 时退化为 OLS
- `Heckman` 两步法：构造已知 ρ 的 DGP，能在合理容差内恢复 β
- `Heckman` 的 IMR 与手算 `φ(zγ)/Φ(zγ)` 一致
- 全部模型：`e` 键存在、`summary(style="stata")` 可渲染
- MLE 方法抛 `UnsupportedError`

### 2.1 零膨胀（`zip` / `zinb`）

```
P(y=0) = π + (1-π)·f(0; μ)
P(y=k) = (1-π)·f(k; μ),  k>0
```

其中 `π` 由 logit 方程给出，`f` 是 Poisson 或 NB 质量函数。

```python
class ZeroInflatedPoisson(_DiscreteBase):
    @classmethod
    def from_formula(cls, formula, data, *, inflate=None)  # inflate 为膨胀方程变量
class ZeroInflatedNegativeBinomial(_DiscreteBase): ...
```

**注意**：statsmodels 的 `ZeroInflatedPoisson` 存在，但参数化（`inflation` vs `inflate`）与 Stata 不同，且默认不报 `ll` 的分解。需要核对后再封装。

### 2.2 零截断（`ztp` / `ztnb`）

```
P(y=k | y>0) = f(k; μ) / (1 - f(0; μ)),  k>0
```

statsmodels 无直接实现，需自研似然（或对 `Poisson` 加 `truncation`）。优先自研，保证可对拍。

### 2.3 截断计数（`tpoisson` / `tnbreg`）

Stata 的 `tpoisson` 用 `ll(#)`/`ul(#)` 截断。与零截断的区别是允许任意上界。

```python
class TruncatedPoisson(_DiscreteBase):
    def __init__(self, endog, exog, *, lower=0, upper=None, param_names=None)
```

**测试要求（TDD）**
- `ZeroInflatedPoisson` 在 `inflate=None` 时退化为普通 Poisson（参数一致 1e-6）
- `zip` 的 `ll` 与手写 `Σ ln[π·1{y=0} + (1-π)·f(y)]` 一致
- `TruncatedPoisson(lower=1)` 与自研的零截断似然一致
- 全部 `e` 键存在、`summary` 可渲染
- 不收敛时抛 `ConvergenceError`
