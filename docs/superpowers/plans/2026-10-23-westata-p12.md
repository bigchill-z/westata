# westata P12 Implementation Plan — 复杂抽样

**Goal:** 实现 `svyset` 与 `svy:` 前缀，覆盖 `mean`、`total`、`proportion`、`regress`、`logit`。

**为什么这批的核心是方差而非点估计：** 所有调查加权点估计都只是加权最小二乘，一行代数。真正难的是**线性化方差**（Taylor series / delta method），而它有若干约定在点估计上完全一致、在标准误第四位后才分开：

1. **有放回 vs 无放回**：`fpc` 是否施加 `(1 - n/N)` 因子
2. **单 PSU 处理**：`singleunit(certainty / scaling / centered)` 三种策略
3. **自由度**：`#PSU - #strata` 还是别的
4. **`n/(n-1)` 修正**与分层求和的具体形式

这些都不是"看起来对就行"的问题——**它们只在第 4 位之后分开**，所以必须用全精度 `e(V)` 对拍，不能只看打印的 6 位小数。这是 P10 的 `ddof` 教训的直接应用。

## Task 1: 设计与线性化方差

**Files:** `src/westata/estimators/survey.py`、`tests/test_survey.py`

### 1.1 `SurveyDesign`（`svyset`）

```python
@dataclass(frozen=True)
class SurveyDesign:
    psu: str
    strata: str | None = None
    weights: str | None = None
    fpc: str | None = None
    singleunit: str = "certainty"    # certainty | scaling | centered | missing

    @classmethod
    def from_frame(cls, frame, *, psu, strata=None, weights=None, fpc=None,
                   singleunit="certainty") -> "SurveyDesign"
    def subsets(self) -> list[np.ndarray]      # 每个（层, PSU）的观测索引
```

### 1.2 线性化方差（**核心，已数值验证**）

通用结构（对**逐观测影响函数** `psi_i`）：

```
V = Σ_h  n_h/(n_h - 1) · Σ_{p∈h} (T_p - T̄_h)(T_p - T̄_h)'
其中 T_p = Σ_{i∈p} psi_i          （PSU 内求和）
     n_h = 层 h 的 PSU 数
```

有 `fpc` 时每层乘 `(1 - n_h/N_h)`。

**各命令的 `psi_i`（全部已验证）**

| 命令 | `psi_i` | 验证差距 |
|---|---|---|
| `svy: mean y` | `y_i / Σw`（再中心化） | **1e-15** |
| `svy: total y` | `w_i y_i` | 见 fixture |
| `svy: regress` | **`(X'WX)⁻¹ w_i x_i e_i`** | **3e-14** |
| `svy: proportion` | 类别二值化后同 `mean` | 见 fixture |
| `svy: logit` | 同 M 估计量影响函数 | 见 fixture |

**`svy: regress` 的陷阱（我第一版就错了）：**
线性化得分**不是** `x_i e_i`，而是 `(X'WX)⁻¹ w_i x_i e_i`——漏掉 `w` 和
`(X'WX)⁻¹` 会让 `V` 相对差 **167%**，而**系数仍精确**。

两种等价写法（都已验证）：
```
逐观测：  psi_i = (X'WX)⁻¹ w_i x_i e_i
三明治：  V = (X'WX)⁻¹ · [Σ_h ... (Σ w x e)] · (X'WX)⁻¹
```

**自由度**：`df_r = #PSU - #strata`。必须在 `e(df_r)` 里报出来。

**`mean` 的缩放**：整体除以 `(Σw)²`。`mean` 的 `psi` 不含 `w`（分母承担权重）——
这一点已由 1e-15 的匹配确认。

**单 PSU 策略**：
- `certainty`：该层只有一个 PSU 时，贡献 0（无方差贡献）
- `scaling`：用全局平均代替（Stata 的 `singleunit(scaling)`）
- `missing`：该层贡献缺失，结果标 NaN

### 1.3 各命令

```python
class SvyMean:      # svy: mean
    @classmethod
    def from_design(cls, variables, frame, design) -> ...
    def fit(self) -> StataResults

class SvyTotal:     # svy: total
class SvyProportion:# svy: proportion
class SvyRegress:   # svy: regress
class SvyLogit:     # svy: logit
```

`model_name`：`"svy: mean"`、`"svy: total"`、`"svy: proportion"`、`"svy: regress"`、`"svy: logit"`。

**`svy: regress` 的系数就是加权 OLS**（`WLS`），所以点估计应等于 `ws.OLS(weights=...)`——这是自检。

**测试要求（TDD）**
- `svy: mean` 的 `b` 与 `V` 对全精度基准（`rel < 1e-10`，因为这是纯代数，应当机器精度）
- `svy: regress` 的 `b` 与 `V` 对全精度基准
- `svy: total`、`svy: logit` 同上
- `svy: regress` 的系数等于加权 OLS（1e-12）
- 当所有权重相等时，`svy: regress` 的系数等于普通 OLS（1e-12）
- `fpc` 使标准误变小（乘 `(1-f)`）
- 单 PSU 层的三种策略行为不同，且 `certainty` 下该层贡献为 0
- `e(df_r)` 等于 `#PSU - #strata`
- 不支持的 `singleunit` 抛 `ValueError`
