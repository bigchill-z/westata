### 1.1 `XtLogit`（`xtlogit`）

三种估计量，语义完全不同，必须分开实现：

**`fe`（条件固定效应）**——`[XT] xtlogit`：Chamberlain (1980) 条件似然。
对每组，只保留 y 不全为 0 也不全为 1 的组（这就是 N 从 960 降到 912 的原因）。
条件似然：

```
P(y_i1..y_iT | Σ_t y_it = k) = exp(Σ_t y_it x_it'β) / Σ_{d: Σd=k} exp(Σ_t d_t x_it'β)
```

分母是所有满足 `Σd=k` 的 0/1 组合之和。T=8 时组合数最多 C(8,4)=70，可穷举。

**`re`（随机效应）**——需对个体效应 `u_i ~ N(0,σ_u²)` 积分：

```
L_i = ∫ Π_t [Λ(x_it'β + u)^{y_it} (1-Λ(...))^{1-y_it}] φ(u/σ_u)/σ_u du
```

用 Gauss-Hermite quadrature，Stata 默认 12 点（`intpoints(12)`）。

**`pa`（总体平均）**——`[XT] xtlogit, pa`：population-averaged GEE，用
exchangeable working correlation。**这是 GEE，不是似然**，标准误需稳健。

```python
class XtLogit:
    @classmethod
    def from_formula(cls, formula, data, *, entity, time, method="re") -> "XtLogit"
    def fit(self, cov_type="nonrobust", *, intpoints=12, maxiter=..., strict=False) -> StataResults
```

`model_name`：`"xtlogit, fe"` / `"xtlogit, re"` / `"xtlogit, pa"`。

### 1.2 `XtProbit`（`xtprobit, re`）

同 `re` 的积分形式，把 Λ 换成 Φ。

### 1.3 `XtTobit`（`xttobit`）

随机效应 Tobit：`y_it = max(ll, x_it'β + u_i + e_it)`，用 quadrature 积分 u_i。

### 1.4 `XtPoisson` / `XtNbreg`（fe/re）

- `fe`：Poisson 的固定效应可**条件化**（多项似然），精确；NB 的 fe 不可条件化，
  Stata 用 `xtnbreg, fe` 的拟似然，**需注明不是真似然**
- `re`：对 u_i 积分

**测试要求（TDD）**
- `xtlogit, fe` 系数与 Stata 对拍（1e-3）；**N 必须恰好是 912**
- `xtlogit, fe` 只用 y 有变异的组（构造一个全 0 的组，断言被剔除）
- `xtlogit, re` 与 `xtlogit, fe` 在无个体效应 DGP 上接近
- `xttobit` 在 ll 极小时接近 `xtreg, re`
- `xtpoisson, fe` 与 `xtpoisson, re` 都收敛，参数有限
- `e()` 键完整、`summary` 可渲染
- 不支持的方法抛 `UnsupportedError`

### 2.1 `XtIvreg`（`xtivreg`）

`fe`：组内变换后对 `(endog = z)` 做 2SLS。
`re`：`[XT] xtivreg` 的 G2SLS——先做 RE 的准去均值，再 2SLS。

```python
class XtIvreg:
    @classmethod
    def from_formula(cls, formula, data, *, entity, time, method="fe") -> "XtIvreg"
    # formula: "y ~ w + (endog = z)"  —— patsy 不支持括号，需自定义解析
```

**解析要求**：把 `y ~ w + (endog = z)` 拆成 `depvar=y`、`exog=[w]`、
`endog=[endog]`、`instruments=[z]`。参照 `estimators/iv.py` 的 `from_formula` 做法。

### 2.2 `XtGls`（`xtgls`）

`[XT] xtgls`：GLS 处理面板误差结构。
- `panels(heteroskedastic)`：每组自己的 σ_i²
- `panels(correlated)`：加组间同期相关
- `corr(ar1)` / `corr(psar1)`：组内自相关

首期至少实现 `panels(heteroskedastic)`（fixture 用的是这个）。

### 2.3 `XtPcse`（`xtpcse`）

`[XT] xtpcse`：OLS + panel-corrected standard errors（Beck & Katz）。
`V = (X'X)^-1 (Σ_i X_i' e_i e_i' X_i) (X'X)^-1`，含小样本修正 `N/(N-k) * T/(T-1)`。

### 2.4 `XtUnitroot`（`xtunitroot`）

`ips`（Im-Pesaran-Shin）与 `llc`（Levin-Lin-Chu）。
**注意**：`dfuller` 的滞后选择规则会影响结果，必须与 Stata 的 `lags()` 默认一致。

**测试要求（TDD）**
- `xtivreg, fe` 系数与 Stata 对拍（1e-3）
- `xtivreg` 公式解析正确分离 exog / endog / instruments
- `xtgls, panels(heteroskedastic)` 系数等于 OLS，只有标准误不同
- `xtpcse` 标准误 > OLS 标准误（通常）
- `xtunitroot ips/llc` 统计量有限，p 值在 [0,1]
- 不支持的面板设定抛 `UnsupportedError`

### 为什么单列

`xtabond`/`xtdpd`/`xtdpdsys` 的核心难点不在优化，而在**工具变量集的构造**：

- `xtabond, lags(1)` 在差分方程中用 `L(2/.).y` 作 GMM 工具 → 30 个工具
- `xtdpdsys` 增加水平方程，工具数变 37
- 工具数决定权重矩阵维度，进而决定**所有**标准误
- Stata 报告 Sargan/Hansen/AR(1)/AR(2)，其构造在手册中**未完全给出**

**已从手册核实（`[XT] xtdpd` Methods and formulas，`xtabond` 的公式重定向到它）：**

含 p 阶滞后的差分方程，工具矩阵 `Z_di` 是一个 **`(T-p-1) x Σ_{m=p}^{T-2} m`** 的
下三角块矩阵。以 p=2、T 为例：

```
Z_di = [ y_i1  y_i2   0     0     0   ... ]
       [  0     0    y_i1  y_i2  y_i3  ... ]
       [ ...                            ... ]
```

即**第 t 行包含 y_{i,1}..y_{i,t-1}**，其余位置填 0。

一步 GMM：

```
Q_xz = Σ_i X_i' Z_i
Q_zy = Σ_i Z_i' y_i
A1   = ( Σ_i Z_i' H1_i Z_i )^-1
W1   = Q_xz A1 Q_xz'
β̂1   = W1^-1 Q_xz A1 Q_zy
```

`H_di` 是差分误差的协方差结构（手册续页给出）。标准误需按 `[XT] xtdpd` 的
sandwich 公式，注意其小样本修正。

**验收**：`e(instruments)` 必须等于 Stata 的 "Number of instruments"（fixture 中
`xtabond, lags(1)` 是 **30**）。这个数字是工具矩阵构造是否正确的强判别式——
它比系数更容易出错，也更容易验证。

```python
class XtAbond:
    @classmethod
    def from_formula(cls, formula, data, *, entity, time, lags=1) -> "XtAbond"
    def fit(self, *, twostep=False, robust=False, maxiter=..., strict=False) -> StataResults
```

**验收标准（可协商）**：
- 系数与 Stata 对拍（1e-2）—— 一步 GMM 应该能精确
- `e(instruments)` 数量必须等于 Stata 的 "Number of instruments"
- Sargan/Hansen **不要求**精确，若无法确定就标 E1 并说明

**如果 T3 无法达到系数一致，必须如实报告，不得用 Sargan 凑数掩盖。**
