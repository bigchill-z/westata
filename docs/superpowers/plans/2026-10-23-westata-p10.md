## Task 1: 系统方程

**Files:** `src/westata/estimators/systems.py`、`tests/test_systems.py`

### 1.1 `Sureg`（`sureg`）

SUR 的可行 GLS：

1. 对每个方程单独 OLS，得到残差 `e_i`
2. 估计跨方程协方差 `Σ̂_ij = e_i'e_j / T`
3. `β̂_SUR = (X' (Σ̂^-1 ⊗ I) X)^-1 X' (Σ̂^-1 ⊗ I) y`

```python
class Sureg:
    @classmethod
    def from_formula(cls, equations: list[str], data, *, names=None) -> "Sureg"
    def fit(self, cov_type="nonrobust", *, iterate=False) -> StataResults
```

`equations` 形如 `["y1 ~ x1 + x2", "y2 ~ x2 + x3"]`。

**关键**：
- 参数名必须用**方程前缀**：`y1:x1`、`y2:x2`、`y1:_cons`
- 协方差是 `(k1+k2) x (k1+k2)` 完整矩阵，**不是块对角**
- 若 `iterate=True` 且未实现，抛 `UnsupportedError`

**测试重点**：
- 系数与 Stata 对拍（1e-4）
- **标准误与 Stata 对拍** — 这是 sureg 存在的理由
- 若两方程残差无关（`Σ̂` 对角），SUR 系数必须等于逐方程 OLS（1e-10）
- 当 `Σ̂` 有强相关时，SUR 标准误必须**小于** OLS 标准误

### 1.2 `Mvreg`（`mvreg`）

多元回归：每个方程含相同回归元，等价于逐方程 OLS 系数，但 VCE 用跨方程协方差。

```python
class Mvreg:
    @classmethod
    def from_formula(cls, formula: str, data) -> "Mvreg"  # "y1 y2 = x1 x2 x3"
    def fit(self) -> StataResults
```

**测试**：系数等于逐方程 OLS（1e-10）；VCE 不同于 OLS。

### 1.3 `Eivreg`（`eivreg`）

误差变量回归。给定信度比 `λ`，修正衰减偏误：

```
β_EIV = (X'Ω^-1 X)^-1 X'Ω^-1 y,  Ω = diag(λ_i) 对带误差变量
```

```python
class Eivreg:
    @classmethod
    def from_formula(cls, formula, data, *, reliab: dict[str, float]) -> "Eivreg"
```

**测试**：`reliab=1.0` 时退化为 OLS（1e-10）；`reliab=0.7` 时系数与 Stata 对拍。

### 1.4 `Manova`（`manova`）

按 `[MV] manova` 的 Wilks' lambda 等四个统计量。首期只做 Wilks' lambda 与 F 近似。

**测试**：Wilks' lambda 与 Stata 的 0.4290 对拍（1e-3）。

## Task 2: 非线性与前沿

**Files:** `src/westata/estimators/nonlinear.py`、`tests/test_nl.py`

### 2.1 `Nl`（`nl`）

非线性最小二乘，参数语法 `{name}`：

```python
class Nl:
    @classmethod
    def from_formula(cls, formula: str, data, *, start: dict | None = None) -> "Nl"
    # formula: "y = {b0} * exp(-{b1} * x)"
    def fit(self, *, maxiter=200, strict=False) -> StataResults
```

**解析要求**：把 `y = {b0} * exp(-{b1} * x)` 转成可求值函数。**不要用 `eval`**，用 `ast` 白名单（参考 `postestimation/nonlinear.py` 的做法）。

**测试**：`/b0`、`/b1` 与 Stata 对拍（1e-3）；参数名带 `/` 前缀如 Stata。

### 2.2 `Frontier`（`frontier`）

随机前沿，半正态无效率项：

```
y = x'b + v - u,  v ~ N(0, σ_v²),  u ~ |N(0, σ_u²)|
```

对数似然标准形式，用 `σ² = σ_v² + σ_u²`、`λ = σ_u/σ_v` 参数化。

```python
class Frontier:
    @classmethod
    def from_formula(cls, formula, data, *, distribution="halfnormal") -> "Frontier"
```

**测试**：系数与 Stata 对拍（1e-2）；报告 `sigma_u`、`sigma_v`、`lambda`。
