docs: retract a wrong claim about qreg fweight -- it was my probe's row-order bug

Round 5 recorded that `qreg [fweight]` is scale-invariant and NOT equivalent to expanding rows, and wrote it into
GAP_REGISTER 8.18 as a cautionary tale. That claim is false, and every number behind it came from one measurement
error.

`bsampl_w.ado` contains `sort r w`, which PERMANENTLY reorders the Stata dataset. So `w` read back afterwards is
in sorted-draw order while the Python frame is still in the original order:

    python frame y:  [-0.395301, 0.263915, 0.607128, -0.972160, ...]
    Stata y (read):  [-0.972160, 0.782979, 0.607128,  0.595216, ...]

Pairing a sorted weight column with an unsorted dependent variable produced all three observations:

    "2w gives the same answer"        -> the same misalignment
    "expansion gives a different one" -> the expansion was built from unsorted columns

Doing it correctly -- reading every column back from Stata so the ordering is consistent:

    qreg [fweight=w]        N=200  [0.90446850, -0.31512561, 1.25192304]
    qreg (rows expanded)    N=200  [0.90446850, -0.31512561, 1.25192304]     IDENTICAL

which is what `[U] 20.24.1` states outright: "the results of running any command with frequency weights should be
the same as running the command on the unweighted, expanded data."

The section is REPLACED rather than annotated, because a wrong explanation left in place is worse than none: 8.18
was written as a lesson and would have taught the next reader a false fact about Stata.

What survives is the other half, which was right: `sqreg`'s variance grows with reps (0.0379 / 0.0490 / 0.0527)
while ours stays near 0.030, so the 3.3e-02 gap is real and still unresolved. The sampling sequence, the weights,
and a single weighted fit all match Stata bit for bit; what does not is the spread of the replicates themselves.

after the xtgls singular-Sigma reading (wrong specification) and the zip comparison (3 parameters against 6). The
pattern in all three: I compared two things without first confirming they described the same quantity.
